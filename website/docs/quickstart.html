Quickstart

Train and predict in minutes

Use this guide to set up dependencies, organize audio files, and train your first model.

1. Setup

python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt

2. Prepare data

Place WAV files under class folders in data/raw/.

data/raw/
  whale_calls/
  ship_noise/
  ambient_ocean/

3. Train a model

python example.py

This loads audio, extracts MFCC features, trains SVM and Random Forest models, and saves the results in models/.

4. Predict audio

python my_prediction.py

Use the saved model to label new audio files.
