Getting started

Your first 30 minutes

A step-by-step guide to install dependencies, verify setup, and train your first underwater audio classifier.

Step 1: Install dependencies

python -m venv venv
venv\Scripts\activate
pip install --upgrade pip
pip install -r requirements.txt

Step 2: Verify installation

python test_classifier.py

Confirm all required libraries are installed correctly.

Step 3: Prepare sample data

python example.py

This creates the folder structure and shows where to add audio files.

Step 4: Train your model

python example.py

Load audio, extract MFCC features, train models, and save results to models/.

Step 5: Make predictions

python my_prediction.py

Use the saved model to label new WAV files.

Troubleshooting basics

  • Ensure audio files are WAV format under data/raw/class_name/.
  • Activate the virtual environment before running scripts.
  • Add more training data if accuracy is low.
