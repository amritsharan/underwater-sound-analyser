Project overview

Underwater Sound Classifier

Classify underwater audio with a practical, beginner-friendly pipeline that combines spectral analysis and fast machine learning models.

Quickstart guide Getting started API reference

Why it matters

Underwater sound classification helps marine research, environmental monitoring, and ship traffic analysis by turning raw audio into consistent labels like whale calls, ship noise, and ambient ocean sounds.

Core features

  • Load WAV audio and resample to 16 kHz with automatic mono conversion.
  • Extract MFCC features and summary statistics (26D feature vector).
  • Train SVM or Random Forest models with built-in evaluation.
  • Visualize spectrograms, MFCCs, and confusion matrices.
  • Save and reuse trained models for batch prediction.

Expected performance

With 50 files per class you can expect 85-95% accuracy using a Random Forest. Accuracy improves as you add more examples. 

10 files/class  -> 60-75% (SVM)
20 files/class  -> 75-85% (SVM)
50 files/class  -> 85-95% (Random Forest)
100+ files/class -> 90-99% (Random Forest)
