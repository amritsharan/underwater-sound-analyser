API reference

UnderwaterSoundClassifier

Key methods and parameters for loading audio, extracting features, and training models.

Constructor

UnderwaterSoundClassifier(model_type='svm', n_mfcc=13, sr=16000)
  • model_type: 'svm' or 'random_forest'
  • n_mfcc: number of MFCC coefficients (default 13)
  • sr: sample rate (default 16000 Hz)

Audio loading

load_audio_file(file_path)
load_audio_files(data_dir, file_extension='.wav')

Load individual files or full class folders.

Feature extraction

extract_mfcc_features(audio)
extract_features()

MFCC feature vectors with mean and standard deviation.

Training and evaluation

train(test_size=0.2)
plot_confusion_matrix()

Train with a train/test split and inspect metrics.

Prediction

predict(audio_file)
predict_batch(audio_directory)

Classify a single file or an entire folder.

Model management

save_model(model_path)
load_model(model_path)

Persist models to disk and load them later.
