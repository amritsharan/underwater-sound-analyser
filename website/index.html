Understand the pipeline in one view

The classifier follows a clear flow: load audio, extract MFCC features, scale them, then train and evaluate. Each step is exposed so you can extend or replace it.

  • Load WAV audio by class
  • Extract MFCC features and stats
  • Normalize with StandardScaler
  • Train SVM or Random Forest
  • Evaluate with accuracy and F1
